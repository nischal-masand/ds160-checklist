# DS-160 Document Checklist

A clean, interactive checklist for collecting all documents needed for a US B1/B2 visa (DS-160) application.

## Features

- 📋 Category-wise document organization
- ✅ Checkbox state persisted in localStorage
- 📊 Floating frosted-glass progress bar
- 📱 Fully responsive (mobile-first)
- 🖨️ Print-friendly layout
- 📤 Share as text (copy to clipboard)

## Tech Stack

Pure HTML, CSS, and vanilla JavaScript — no frameworks, no build step.

## Deployment

This project is deployed on [Vercel](https://vercel.com) via GitHub integration. Every push to `main` triggers an auto-deploy.
